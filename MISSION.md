# Mission: Build & Sell Next.js Landing Pages with AI Assistance

## Why
To build and sell small-business landing pages — single-page promo sites — using Next.js + TypeScript, leaning on AI as a development co-pilot. The goal is to deliver a finished, deployable site or a resellable template each weekend without writing everything from scratch first.

## Success looks like
- Scaffold, customize, and deploy a live Next.js + TypeScript landing page within one weekend
- Prompt an AI to generate, modify, and debug React components and TypeScript types with confidence
- Package the finished site as a reusable, resellable template with a clear pricing story

## Constraints
- Time: weekend-only bursts (5–10 hrs), so each milestone must fit one weekend
- Prior knowledge: basic JS/HTML/CSS and a little Laravel/PHP — fill gaps only as needed, prefer AI scaffolding
- No video — learn by reading code and hands-on building
- Artifacts are real, sellable, not abstract tutorials

## Out of scope
- Backends, databases, auth (a static contact form is enough)
- Advanced React state (Redux, Context beyond local state)
- Hard performance optimization beyond image/SEO basics
- Custom domains beyond one-click Vercel deployments
