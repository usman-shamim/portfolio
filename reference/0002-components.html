Components & JSX Cheat Sheet

Compressed essence of Lesson 1. Print and keep beside your keyboard.

A component is a function

function Button() {
  return <button>Click</button>;
}
// Capital letter is REQUIRED so JSX treats it as a component.

Props = inputs

function Hero({ title }: { title: string }) {
  return <h1>{title}</h1>;
}
<Hero title="Acme" />

JSX expression {title} prints the variable. Props are how info enters a component.

State = memory (reactivity)

'use client';
import { useState } from 'react';

function Toggle() {
  const [on, setOn] = useState(false);
  return (
    <button onClick={() => setOn(!on)}>
      {on ? 'On' : 'Off'}
    </button>
  );
}

TypeScript typing for props

interface CardProps {
  title: string;
  price?: number;      // optional prop
  onBuy: () => void;
}

Conditional rendering

{show && <p>Visible</p>}
{count > 0 ? 'cart full' : 'empty'}
{items.length === 0 && <p>No items</p>}

List rendering

{items.map((item) => (
  <li key={item.id}>{item.name}</li>
))}

key is required when mapping — it lets React update lists efficiently.

Two JSX rules to remember

  • class= becomes className=.
  • Self-close void tags: <br />, <img />.

Importing a component

// components/Hero.tsx → import with the @ alias
import Hero from '@/components/Hero';
<Hero title="Hi" />

Rules

  • Any file using useState, onClick, or other browser APIs must start with 'use client';.
  • Next.js page files are app/page.tsx (route /), app/about/page.tsx (route /about).
