Next.js Commands Cheat Sheet

Compressed essence of Lesson 1. Print this page and keep it beside your keyboard.

Scaffold a new project

npx create-next-app@latest landing --ts --app

landing = project folder. --ts = TypeScript. --app = App Router (modern routes).

Run locally

cd landing
npm run dev
# opens at http://localhost:3000

Deploy to Vercel

One-time CLI setup

npm i -g vercel
vercel

Every deploy after

vercel --prod

Deploy via GitHub (no CLI)

  1. cd landing && git init && git add -A && git commit -m "first"
  2. Git push to a GitHub repo (private is fine).
  3. Import that repo at vercel.com/new — leave defaults, click Deploy.
  4. Copy the *.vercel.app URL it assigns you.

Key file: the home page

app/page.tsx

This is the route for /. Edit it, save, browser reloads instantly. Every page lives under app/ as page.tsx (plus optional layout.tsx).

Common pitfalls

  • If npx is not found: install Node.js 18+ from nodejs.org.
  • If port 3000 is busy: the terminal offers another port — use it.
  • If Vercel asks to "Link to existing project": type no and re-run vercel inside your project folder.
