# Next.js + TypeScript Resources

## Knowledge

- [Next.js Official Docs](https://nextjs.org/docs)
  The canonical reference. Start with Learn (nextjs.org/learn) then dip into docs as needed. Use for: routing, deployment, Image, Metadata.
- [Next.js Learn](https://nextjs.org/learn)
  Free interactive hands-on tutorial by Vercel. Use for: fastest path from zero to a real Next.js project.
- [React Official Docs (react.dev)](https://react.dev)
  The component model behind every Next.js page. Use for: JSX, props, state.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  Authoritative but dense. Use for: type syntax, interfaces, the any escape hatch.
- [Tailwind CSS Docs](https://tailwindcss.com/docs)
  Utility-first CSS. Use for: styling pages without writing custom CSS — key for fast AI-assisted builds.
- [Vercel Docs](https://vercel.com/docs)
  One-click deployment of Next.js. Use for: deploying your site live and custom domains.
- [create-next-app on GitHub](https://github.com/vercel/create-next-app)
  The scaffold tool. Use for: flags like --ts, --app, --eslint.

## Wisdom (Communities)

- [Vercel Community / Discord](https://vercel.com/community)
  High-signal help for Next.js + deployment. Use for: deploy errors, Image optimization, routing.
- [/r/nextjs](https://reddit.com/r/nextjs)
  Moderated subreddit. Use for: architecture decisions, best practices.
- [/r/webdev](https://reddit.com/r/webdev)
  Broader front-end. Use for: pricing templates, going from dev to selling.
