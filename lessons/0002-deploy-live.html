Lesson 2: Deploy Live in One Click

Weekend 1, part 2. One win: a public URL your future clients can open right now.

A site that only runs on your computer cannot be sold. Vercel deploys Next.js in a single step. This is the same tool Next.js is built by, so the defaults are already optimal.

Option A — Git + dashboard (recommended first time)

  1. Inside your landing project, commit everything to GitHub (private is fine):
git init
git add -A
git commit -m "landing: first hero"
git branch -M main
git remote add origin https://github.com/YOU/landing.git
git push -u origin main
  1. Open vercel.com/new, import your repo, leave every default, and click Deploy.
  2. Copy the *.vercel.app URL. Paste it into a private browser tab — your Hero is live on the internet.

Option B — Vercel CLI (faster after lesson 1)

npm i -g vercel
vercel          # first time only — it links the project
vercel --prod   # every deploy after

Checklist — weekend done when

  • Your public URL loads in a browser you are not logged into.
  • The Hero button toggles the pricing line (state works in production).
  • You bookmarked the deploy command so next time is one line.
